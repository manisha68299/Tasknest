# Tasknest

A tiny to-do list API. You can create tasks, list them, update them, mark them done, and delete them. That's it — no login, no database, nothing fancy. It's basically the smallest thing you could call a "real" API, which is the point.

Built for FlyRank Internship — Backend Track, Week 2, Assignment A1.

## What you need

- Python 3.10 or newer

## Getting it running

```bash
git clone <your-repo-url>
cd tasknest

python3 -m venv .venv
source .venv/bin/activate      # on Windows: .venv\Scripts\activate

pip install -r requirements.txt

uvicorn main:app --reload --port 8000
```

That's it, you're up. Go to http://localhost:8000 in your browser and you should see a little JSON blob back.

Docs are auto-generated by FastAPI and live at http://localhost:8000/docs — that's the Swagger UI, and it lets you actually click through and test every endpoint without writing any curl commands.

## Endpoints

| Method | Path          | What it does                       | Success | Errors   |
|--------|---------------|-------------------------------------|---------|----------|
| GET    | `/`           | API info (name, version)            | 200     | —        |
| GET    | `/health`     | Health check, just says ok          | 200     | —        |
| GET    | `/tasks`      | List every task                     | 200     | —        |
| GET    | `/tasks/{id}` | Get one task                        | 200     | 404      |
| POST   | `/tasks`      | Create a task                       | 201     | 400      |
| PUT    | `/tasks/{id}` | Update a task's title and/or done   | 200     | 400, 404 |
| DELETE | `/tasks/{id}` | Delete a task                       | 204     | 404      |

A task looks like this:

```json
{ "id": 1, "title": "Learn FastAPI", "done": false }
```

## Trying it out with curl

Here's the full lifecycle, ran against a fresh server — create a task, read it back, update it, delete it, then confirm it's actually gone:

```
$ curl -i http://localhost:8000/
HTTP/1.1 200 OK
content-type: application/json

{"name":"Task API","version":"1.0","endpoints":["/tasks"]}

$ curl -i http://localhost:8000/health
HTTP/1.1 200 OK
content-type: application/json

{"status":"ok"}

$ curl -i http://localhost:8000/tasks/1
HTTP/1.1 200 OK
content-type: application/json

{"id":1,"title":"Learn FastAPI","done":false}

$ curl -i http://localhost:8000/tasks/99
HTTP/1.1 404 Not Found
content-type: application/json

{"error":"Task 99 not found"}

$ curl -i -X POST http://localhost:8000/tasks -H "Content-Type: application/json" -d '{"title":"Buy milk"}'
HTTP/1.1 201 Created
content-type: application/json

{"id":4,"title":"Buy milk","done":false}

$ curl -i -X POST http://localhost:8000/tasks -H "Content-Type: application/json" -d '{}'
HTTP/1.1 400 Bad Request
content-type: application/json

{"error":"Title is required and cannot be empty"}

$ curl -i -X PUT http://localhost:8000/tasks/1 -H "Content-Type: application/json" -d '{"done":true}'
HTTP/1.1 200 OK
content-type: application/json

{"id":1,"title":"Learn FastAPI","done":true}

$ curl -i -X DELETE http://localhost:8000/tasks/1
HTTP/1.1 204 No Content

$ curl -i http://localhost:8000/tasks/1
HTTP/1.1 404 Not Found
content-type: application/json

{"error":"Task 1 not found"}
```
